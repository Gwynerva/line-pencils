%N Number of distinct values taken by the number of intersection points of n lines in the plane, no two parallel.
%S 1, 1, 2, 3, 5, 9, 13, 18, 24, 30, 38, 46, 56
%O 1,3
%C The number of intersection points of n lines, no two parallel, lies between 1 and binomial(n,2) (for n = 1 it is 0); a(n) is the number of values that occur. Dually, a(n) is the number of distinct numbers of lines determined by n points in the plane (Grünbaum's problem). Erdős (1972) and Salamon and Erdős (1988) determined the set of these values for all sufficiently large n.
%C The values binomial(n,2) - 1 and binomial(n,2) - 3 never occur. For n >= 10 no value strictly between n and 2n-4 occurs (Elliott). For n >= 13 the values below 2n-1 are exactly 1, n, 2n-4 and 2n-2. In particular 2n-3 intersection points are impossible for n >= 12: for n = 12 by exhaustive computation, for n >= 13 by a computer-assisted counting argument based on the inequalities of Melchior and Hirzebruch.
%C a(n) = binomial(n,2) - 2n + 4 for n = 12 and n = 13, and 65 <= a(14) <= 67. The formula does not hold for all n: at n = 17 the value 2n-1 = 33 is also impossible.
%C The multisets of numbers of lines through the intersection points are counted by A399464.
%C Differs from A129230: a(n) = A129230(n-2) for 4 <= n <= 12, but A129230(11) = 55 while a(13) = 56.

%e For n = 4 the possible numbers of intersection points are 1, 4 and 6, so a(4) = 3. Four lines not all through one point have at least four intersection points, and 5 is impossible: three lines through one point merge three intersection points into one, which reduces the count from 6 to 4.
%e For n = 5 the possible numbers are 1, 5, 6, 8 and 10, so a(5) = 5.
